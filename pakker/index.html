Ofte stilte spørsmål

Hva trenger du fra meg?

Logo, bilder, tekstutkast eller stikkord, kontaktinformasjon og tilgang til domenet. Du får to tilbakemeldingsrunder.

Hva skjer hvis jeg ikke har tekst eller bilder?

Det avtaler jeg med deg i tilbudet. Jeg kan hjelpe med tekstutkast laget med AI som du godkjenner, og du kan bruke bildene du har.

Hva betyr «klar for AI-søk»?

Strukturerte data, FAQ, llms.txt og tydelig tekst som gjør det enklere for Google og AI-tjenester å forstå bedriften din. Les mer på Klar for AI-søk.

Kan jeg endre siden selv?

Siden er statisk og rask. Små endringer kan jeg gjøre via Vedlikehold. Større endringer avtales separat.

Hvilke språk kan nettsiden ha?

Nettsiden kan lages på norsk, engelsk, svensk, polsk eller andre språk – du velger språkene kundene dine bruker.
